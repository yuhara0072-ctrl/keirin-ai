# 競輪観測AI

netkeirin のデータから **市場の偏り**（回収率・オッズ歪み）を見つけるための最小構成ツールです。

## できること

- 出走表・オッズ・結果の取得と SQLite 保存
- **毎日複数レース**の一括取得（`daily`）
- **競輪場別 / 時間帯別 / 脚質別**の回収率分析
- **AI予測強化指標**（ライン・逃げ人数・人気集中率・荒れ指数・本命決着率・万車券率・競輪場別傾向）
- **AIスコア**（総合スコア・危険度・荒れ予想・本命信頼度・期待値ランク・おすすめ買い目TOP3）
- **AIおすすめ強化**（狙い目TOP3・見送り・危険な人気・判定・理由表示・カードUI）
- **ライン分析**（ライン長・番手有利・単騎・先行ライン・自力型・地区連携・ライン別AIスコア）
- **グラフ**（Plotly: 回収率推移・競輪場ランキング・AIスコア分布・的中率推移）
- **市場監視**（オッズ急変・異常売れ・人気集中・危険本命・穴急上昇・歪みランキング）
- **学習機能**（過去結果から勝ちパターンを学習し AI スコアへ加点/減点）
- **レース直前モード**（T-30/T-10/T-0 オッズ記録・直前分析・直前補正スコア）
- **自動運用モード**（ホームからワンクリック / 朝6時自動 / 取得→分析→学習→レポート→通知）
- **予測AI（XGBoost）**（回収率・期待値・信頼度・特徴量重要度）
- **通知ログ**（高スコア・危険人気・急変アラートのDB記録）
- **バックアップ**（DB・設定・レポートの保存と復元）
- **収支検証**（購入記録・AIスコア別成績・仮想購入成績）
- **オッズ歪み・異常**の検知
- レポートの **txt 保存**（Streamlit 画面でも表示）

## 毎日の運用手順（推奨）

機能追加より **データ収集と検証** を優先してください。AI信頼度は有効データ件数で自動判定されます。

### AI信頼度（有効データ基準）

| 信頼度 | 有効データ | 運用の目安 |
|--------|-----------|-----------|
| **データ不足** | 100件未満 | 収集優先。判断は参考程度 |
| **参考レベル** | 100〜299件 | 傾向確認OK。実戦は控えめ |
| **検証可能** | 300〜999件 | 検証レポート・改善提案を活用 |
| **実戦レベル** | 1000件以上 | 実戦判定・資金管理を本格運用 |

ホーム画面の **100 / 300 / 1000** 進捗バーで収集状況を確認できます。

## レポートの見方

| セクション | 意味 |
|------------|------|
| 競輪場別回収率 | 場ごとに「全組み合わせ100円ずつ買った」ときの回収率 |
| 時間帯別 | モーニング / ナイター 等（発走時刻から自動判定） |

| オッズ歪み | 投票の偏り・本命集中・的中の過小評価 |

### AI予測強化指標の見方

| 指標 | 意味 |
|------|------|
| ライン情報 | netkeirin 並び予想 API（`0` でライン区切り。例: `3-1 \| 5-4-2`） |
| 逃げ人数 | 出走表の脚質「逃」の人数 |
| 競輪場別傾向 | 場ごとの平均逃げ・ライン本数・人気集中・荒れ指数・本命決着率・万車券率 |
| 人気集中率 | 3連単1番人気の暗黙確率シェア（%）。高いほど本命に票が集中 |
| 荒れ指数 | オッズ分散と本命シェアから算出（0〜100）。高いほど波乱しやすい傾向 |
| 本命決着率 | 1番人気3連単が的中したレースの割合 |
| 万車券率 | 3連単払戻1万円以上、または的中オッズ100倍以上の割合 |

Streamlit の **AI予測指標** タブ、または `python main.py ai` で確認できます。

| 期待値ランク | S(80+) / A(65+) / B(50+) / C(35+) / D |

| 荒れ予想 | 荒れやすさの目安 |

## 注意事項

- データ元は [netkeirin](https://keirin.netkeiba.com/) です。利用規約・マナーを守り、`config.py` の `REQUEST_INTERVAL`（1秒）で負荷を抑えています。
- 投票・投資の判断は自己責任で行ってください。本ツールは観測・分析用途です。
- 分析の回収率は「全組み合わせに均等100円」のシミュレーションです。実際の購入方法とは異なります。

## 設定の変更

`config.py`:

- `DAILY_FETCH_LIMIT = 5` … 毎日の取得件数
- `REQUEST_INTERVAL = 1.0` … アクセス間隔（秒）
